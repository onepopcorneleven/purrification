# `src/components/ui/`

Shared design primitives — plain React components wrapping Tailwind
classes, not a separate styling abstraction. See
`docs/design-system.md`'s component inventory: `PageShell`, `Button`,
`Card`, `Field`, `EmptyState`.

Bespoke, non-reusable components (e.g. the diagnosis/ritual result card)
live in `src/components/<feature>/` instead — see
`src/components/diagnosis/`.
